# 魔镜歌词网歌词检索工具

用于从 [魔镜歌词网](https://mojigeci.com/) 检索并下载歌词，支持：

- 交互式选择歌曲
- 下载原文歌词（`.lrc`）和繁体歌词（`.cht.lrc`）
- 可选生成 ASS 字幕（`.ass` / `.cht.ass`）
- 可选去除时间戳，仅保留纯文本歌词

## 环境要求

- Go 1.22+（建议）

## 安装与运行

### 直接运行

```bash
go run . "乃木坂46 気づいたら片想い"
```

程序会展示候选歌曲列表，使用方向键选择后回车确认下载。

### 编译后运行

```bash
go build -o mojim-lrc-downloader .
./mojim-lrc-downloader "乃木坂46 気づいたら片想い"
```

## 使用说明

### 单关键词搜索

```bash
go run . "关键词"
```

### 从文件批量读取关键词

先准备一个文本文件（每行一个关键词）：

```txt
乃木坂46 気づいたら片想い
乃木坂46 ロマンスのスタート
乃木坂46 吐息のメソッド
```

再执行：

```bash
go run . -i input.txt
```

## 常用参数

```bash
go run . [flags] [关键词]
```

- `-i, --input`：读取关键词文件（每行一个关键词）
- `-o, --output`：输出目录，默认 `downloads`
- `-s, --strip`：去除 `.lrc` 里的时间戳，仅保留歌词文本
- `-a, --ass`：额外生成 ASS 字幕文件

示例：

```bash
go run . -o ./lyrics -a -s "乃木坂46 気づいたら片想い"
```

## 输出文件

默认会生成两份 LRC 文件：

- `<歌曲ID> <歌手> - <歌名>.lrc`
- `<歌曲ID> <歌手> - <歌名>.cht.lrc`

如果启用 `-a/--ass`，还会额外生成：

- `<歌曲ID> <歌手> - <歌名>.ass`
- `<歌曲ID> <歌手> - <歌名>.cht.ass`

## 注意事项

- 歌词下载过程是交互式选择，不是自动下载搜索结果第一项。
- 关键词包含空格时建议加引号。
- 暂未添加分页搜索，设置多个关键词有利于缩小搜索范围。
